FOR SHRUTI — WEBSITE SETUP

1. Keep all files and folders together. Open index.html to preview the website on your computer.
2. Edit config.js:
   - Password is OFF by default. To turn it on, change enabled: false to enabled: true.
   - Change value to the password you want.
   - To add music, put an MP3 file in assets/music/ and set musicFile to its path.
3. Replace assets/photos/photo1.jpg, photo2.jpg and photo3.jpg with your own photos. Keep those exact filenames.
4. Edit the letter text in index.html to make it personal.

GITHUB PAGES (FREE)
1. Create a new public repository named: for-shruti
2. Extract this ZIP on your computer.
3. Open the repository on GitHub, choose Add file > Upload files.
4. Upload the CONTENTS of the for_shruti folder (index.html, config.js, script.js, styles.css, README.txt and assets folder), not the outer ZIP.
5. Commit the upload.
6. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a minute or two. Your site will be at:
   https://YOUR-GITHUB-USERNAME.github.io/for-shruti/

IMPORTANT
- GitHub Pages is public. A password screen is only a visual gate, not strong security; the website files can still be viewed by someone technically skilled.
- Do not put private or sensitive information on a public GitHub Pages site.
- Background music will only play after the visitor taps Play music. Use music you have permission to share.
